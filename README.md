# Process Standards and Templates

[TOC]

**Description**

Standard Operating Procedures \(SOPs\), process standards, are Step-by-step instructions that explain how to complete common tasks and processes consistently across the project.

If your project contains multiple containers do not assume an ACG / Design Document / Diagram for each container.  Treat  your application as a whole system and document to that level, not individual components.

Templates are ready-to-use formats for documents, reports, forms, and other materials that team members need regularly.

Use the \*_Standard.md documents as a reference of what should be and what is possible.  Strict adherence to every principle enumerated in the standard is not necessarily advised.  Utilize all of the high level concepts (Project Planning to Testing) but tailor the Standard based on your team's experience and resources.

The \*_Template.md documents are intended to represent a reference implementation from the Standard and a start guide for your own tailored solution.  Templates also represent the minimal amount of data required for an application.
